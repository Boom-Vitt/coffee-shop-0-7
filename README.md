# BoomBigNose+ Coffee Shop

เว็บไซต์ร้านกาแฟภาษาไทย (BoomBigNose+ Coffee Shop) สร้างด้วย Vite มีเมนูกาแฟร้อน กาแฟเย็น เบเกอรี่ แกลเลอรี่ เกมทดสอบความรู้เรื่องกาแฟ รีวิว และตะกร้าสินค้าพร้อมคำนวณราคา หน้าเว็บอยู่ที่ src/index.html ติดตั้งด้วย npm install แล้วรัน npm run dev หรือ npm run build เพื่อสร้างไฟล์สำหรับเผยแพร่
